# Superstore Sales & Profit Analysis Dashboard

This is my first end-to-end Excel dashboard project, built 
while learning Data Analytics. I used the Superstore dataset 
to practice Pivot Tables, Power Query, and building an 
interactive dashboard with slicers.

# What I Analyzed
- Sales and Profit performance by Region and Category
- Customer segment breakdown
- Time-based trends using Quarter filters

# Key Findings
While analyzing, I noticed that Technology performs best 
overall in both Sales and Profit. But Furniture, despite 
decent sales, is barely profitable — and in the Central 
region specifically, it's actually running at a loss 
(-$2,871). This suggests a discounting or cost issue 
worth investigating.

I also noticed West region leads overall, but Central 
struggles with profit while South struggles with sales — 
two different problems needing different solutions.

# Tools Used
Excel — Pivot Tables, Power Query, Interactive Slicers,
pivot charts

# Key Metrics
Total Sales: $22,97,200.86;
Total Profit: $2,86,397.02;
Profit Margin: 12.47%
